# Print600.ru - ввод данных
[**⬇️ Скачать последнюю версию**](https://github.com/aleksfrosto/Print600---PDF/releases/download/1.7/Print600mass.filling.of.PDF.exe)

Программа размножает макет (PDF, JPG, PNG или TIFF) по списку ФИО или с нумерацией (в том числе двойной и тройной — сектор, ряд, место): каждая запись — отдельная страница макета с подставленным текстом. Результат сохраняется одним многостраничным PDF.

## Портативная версия (рекомендуется)

Файл `Print600.ru.exe` — вся программа целиком. Установка не нужна, Python не нужен. Скопируйте exe в любую папку (или на флешку) и запустите.

- Первый запуск занимает несколько секунд: программа распаковывается во временную папку.
- Рядом с exe появится папка `Print600.ru_data` с настройками — они переезжают вместе с программой. Если в папку с exe нельзя писать (например, Program Files), настройки сохранятся в профиль пользователя.
- Exe не подписан цифровой подписью, поэтому Windows при первом запуске может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Некоторые антивирусы настороженно относятся к программам, собранным PyInstaller; при ложном срабатывании добавьте файл в исключения.
- Работает на Windows 8.1, 10 и 11 (64-бит).

## Запуск из исходников и самостоятельная сборка

Нужен Python 3.9 или новее (python.org, при установке отметить «Add python.exe to PATH»).

- `run.bat` — запуск без сборки (при первом запуске сам установит нужные пакеты).
- `build_exe.bat` — собрать `dist\Print600.ru.exe` самостоятельно.

## Как пользоваться

Настройки разбиты на шесть разделов. Щелчок по голубому заголовку сворачивает или разворачивает раздел; в заголовке видна краткая сводка.

1. **Макет PDF** — щёлкните по пустому окну предпросмотра, перетащите PDF мышью или нажмите «Открыть…».
2. **Место на макете** — щёлкните по макету, и текст встанет в эту точку; потяните за текст, чтобы сдвинуть. Или введите X и Y в миллиметрах. «Макс. ширина» по умолчанию равна ширине макета: если текст не помещается, кегль уменьшается автоматически.
3. **Данные** — вверху выбор **«Список ФИО» / «Нумерация»**.
   - *Список ФИО*: по одной записи в строке; Ctrl+V, правая кнопка мыши, загрузка `.xlsx`/`.csv`/`.txt` или перетаскивание файла.
   - *Нумерация*: см. ниже.
4. **Шрифт** — семейство, размер, **Ж** / *К* / <u>Ч</u>.
5. **Цвет** — CMYK или RGB, пипетка с панелью шкал (щёлкать можно сколько угодно раз; выход — Esc, «Готово» или крестик).
6. **Перенос на новую строку** — какие по счёту пробелы заменить переносом («1» — фамилия отдельно; для нумерации «Ряд 5» → «Ряд» над «5»).

Кнопка **«Сформировать PDF…»** всегда видна внизу слева.

В верхней строке над предпросмотром: значки отмены и возврата (подсказка появляется при наведении), **«Сбросить настройки»** — вернёт шрифт, цвет, место, нумерацию и перенос к исходным (макет и список останутся, а сам сброс отменяется по Ctrl+Z), и **«Поддержать разработку»**. Строкой ниже — ссылка «Напечатать быстро и дешево можно тут — print600.ru», справа выбор масштаба. **Ctrl+Z** — отменить последнее действие, **Ctrl+Y** — вернуть.

## Нумерация

**Количество номеров:** 1, 2 или 3 (например, номер билета; ряд и место; сектор, ряд и место).

**Для каждого номера:** «с … по …», шаг, «цифр» (минимум знаков: 3 → 001), текст до и после. Пробелы учитываются: «от » + 1 + « шт» = «от 1 шт». Диапазон может идти и по убыванию.

**Порядок страниц:** «последний номер меняется чаще» (1-1-1, 1-1-2, 1-1-3 …) или «первый номер меняется чаще» (1-1-1, 2-1-1, 3-1-1 …). Второй вариант удобен для резки стопой.

**Размещение:** «в одной строке» — все номера одним текстом («Ряд 5, место 3»; разделитель впишите в «текст до» следующего номера); «отдельно» — у каждого номера своё место на макете, свой шрифт, цвет и перенос.

**Выбор номера для настройки.** При размещении «отдельно» сверху слева появляется полоса «Настраиваются: Все номера / Номер 1 / Номер 2 / Номер 3».
- **«Все номера»** (по умолчанию) — изменения применяются сразу ко всем: шрифт, размер, цвет, выравнивание становятся одинаковыми, а перемещение сдвигает номера вместе, сохраняя расстояния между ними. Меняются только те настройки, которые вы трогаете: если у одного номера свой цвет, смена размера для всех его не тронет.
- **Один номер** — настраивается только он. Выбрать можно кнопкой или двойным щелчком по номеру на макете. Перетаскивание за текст двигает только этот номер.

**Отдельный шрифт и цвет для номера:** в разделах «Шрифт» и «Цвет» отметьте «Номер — своим шрифтом и цветом» и переключайтесь между «Слова» и «Номер». Например, «РЯД» — 11 pt обычным, а число — 22 pt жирным красным.

Под настройками видно «Итого: 2 × 3 × 4 = 24 макета» и пример первой и последней записи.

## Язык интерфейса

В правом верхнем углу переключатель **RU | EN**. Язык меняется сразу, без перезапуска: макет, список, настройки и история отмены сохраняются. Выбранный язык запоминается.

## Полезно знать

- Шрифт встраивается в PDF (только нужные символы), так что файл откроется где угодно.
- Если в шрифте нет каких-то букв из списка (например, «Ё»), программа предупредит до формирования.
- В правом верхнем углу предпросмотра — размер макета в мм и координаты курсора. Внизу — ширина текста, итоговый кегль и число строк. «Самая длинная» показывает запись, которая хуже всего влезает.
- Все настройки (последний макет, шрифт, цвет, позиция) запоминаются между запусками.
- Русские буквы в именах файлов и папок поддерживаются.
- Макет-картинка вставляется в результат один раз и переиспользуется на всех страницах, поэтому файл остаётся небольшим. JPG сохраняет исходное сжатие; для печати всё же лучше PDF, потому что у картинок нет цветов CMYK и векторной графики.
- Если что-то пошло не так, программа покажет окно с ошибкой и запишет подробности в `Print600.ru_data\error.log` — пришлите этот файл разработчику.
